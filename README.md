# FakhArt — Boutique en ligne de produits artisanaux marocains

> Projet collectif réalisé dans le cadre du **Brief 2 — Plateforme e-commerce** à YouCode.

## 1. Présentation du projet

FakhArt est une maquette de boutique en ligne dédiée aux produits artisanaux marocains. L'objectif est de transformer une maquette Figma en une interface web responsive, accessible et fidèle au design fourni.

Le projet couvre uniquement la partie visible du site : **aucun paiement, aucune base de données et aucune sauvegarde réelle du panier ou des formulaires**. Les interactions restent statiques dans le cadre de ce brief. JavaScript n'est pas utilisé.

## 2. Objectifs

- Intégrer les cinq pages à partir de la maquette Figma.
- Utiliser HTML5 sémantique et Tailwind CSS v4.
- Adopter une approche **mobile-first**.
- Réutiliser les composants et respecter le Design System commun.
- Appliquer les bases de l'accessibilité : textes alternatifs, navigation au clavier, focus visible, contrastes suffisants et libellés explicites.
- Collaborer avec Git Flow, les Pull Requests et le suivi des tâches.

## 6. Technologies utilisées

- **HTML5** — structure sémantique des pages.
- **Tailwind CSS v4** — mise en forme avec des classes utilitaires.
- **Node.js et npm** — environnement et scripts de compilation CSS.
- **Git et GitHub** — gestion des versions, branches et Pull Requests.
- **Figma** — maquette, Design System et composants.
- **GitHub Projects** — suivi des tâches de l'équipe.

Aucun framework JavaScript n'est utilisé. Le brief ne demande pas de JavaScript.



## 10. Responsive design et accessibilité

| Appareil | Largeur de référence |
|---|---:|
| Mobile | 375 px |
| Tablette | 768 px |
| Ordinateur | 1280 px |

Ce projet nous permet de mettre en pratique l'intégration web à partir d'une maquette, le responsive design, l'accessibilité, la création de composants réutilisables et le travail collaboratif avec Git.
